# public-complaint-platform
생활 민원 접수 및 처리 현황 조회 시스템

## 프로젝트 소개

**public-complaint-platform**은 학교 주변에서 발생하는 생활 불편 민원을 웹에서 접수하고, 처리 현황을 조회할 수 있는 민원 관리 시스템입니다.

사용자는 민원을 등록하고 처리 상태를 확인할 수 있으며, 관리자는 접수된 민원을 확인하고 상태를 변경하거나 답변을 작성할 수 있습니다.

## 프로젝트 목적

학교 주변에서 발생하는 시설물 파손, 청결 문제, 소음, 조명 문제 등 생활 불편 사항을 온라인으로 접수하고 관리할 수 있도록 하여 민원 처리 과정을 효율적으로 관리하는 것을 목표로 합니다.

## 주요 기능

### 일반 사용자 기능

- 회원가입
- 로그인
- 민원 등록
- 내 민원 조회
- 민원 상세 조회
- 민원 처리 상태 확인
- 지도에서 민원 위치 확인

### 관리자 기능

- 전체 민원 목록 조회
- 민원 상세 확인
- 민원 상태 변경
- 관리자 답변 작성
- 상태별 / 카테고리별 민원 필터링

## 민원 처리 상태

| 상태 | 설명 |
|---|---|
| 접수 | 사용자가 민원을 등록한 상태 |
| 검토중 | 관리자가 민원 내용을 확인 중인 상태 |
| 해결중 | 실제 조치가 진행 중인 상태 |
| 해결완료 | 민원 처리가 완료된 상태 |
| 반려 | 민원 요건에 맞지 않아 처리하지 않는 상태 |

## 민원 카테고리

| 카테고리 | 예시 |
|---|---|
| 시설물 파손 | 벤치 파손, 문 고장, 난간 파손 |
| 청소/쓰레기 | 쓰레기 방치, 화장실 청결 문제 |
| 소음 | 공사 소음, 야간 소음 |
| 조명/안전 | 가로등 고장, 어두운 통로 |
| 도로/보행 | 보도블록 파손, 통행 불편 |
| 주차/자전거 | 불법주차, 자전거 방치 |
| 기타 | 기타 생활 불편 사항 |
