# 요구사항 명세서

## 1. 기능적 요구사항

<table>
  <thead>
    <tr>
      <th>대분류(기능)</th>
      <th>중분류(기능)</th>
      <th>상세설명</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td rowspan="4">회원 관리 기능</td>
      <td>사용자 회원가입 기능</td>
      <td>일반 사용자가 이름, 아이디 또는 이메일, 비밀번호 등의 정보를 입력하여 회원가입할 수 있는 기능을 제공한다.</td>
    </tr>
    <tr>
      <td>관리자 계정 기능</td>
      <td>관리자가 별도의 관리자 계정으로 로그인할 수 있도록 하며, 일반 사용자와 구분된 권한을 부여한다.</td>
    </tr>
    <tr>
      <td>로그인 기능</td>
      <td>사용자와 관리자가 아이디 또는 이메일, 비밀번호를 입력하여 시스템에 로그인할 수 있는 기능을 제공한다.</td>
    </tr>
    <tr>
      <td>사용자 권한 구분 기능</td>
      <td>로그인한 계정의 유형이 일반 사용자인지 관리자인지 구분하여 접근 가능한 기능을 제한한다. 일반 사용자는 민원 등록과 조회가 가능하며, 관리자는 민원 처리 상태를 변경할 수 있다.</td>
    </tr>

    <tr>
      <td rowspan="5">민원 등록 기능</td>
      <td>민원 제목 입력 기능</td>
      <td>사용자가 등록하고자 하는 민원의 핵심 내용을 제목으로 입력할 수 있는 기능을 제공한다.</td>
    </tr>
    <tr>
      <td>민원 내용 입력 기능</td>
      <td>사용자가 민원의 상세 상황, 발생 원인, 불편 사항 등을 구체적으로 작성할 수 있는 기능을 제공한다.</td>
    </tr>
    <tr>
      <td>카테고리 선택 기능</td>
      <td>사용자가 민원의 유형을 도로, 시설, 환경, 교통, 기타 등으로 선택할 수 있는 기능을 제공한다.</td>
    </tr>
    <tr>
      <td>지도 위치 선택 기능</td>
      <td>사용자가 민원이 발생한 위치를 지도에서 선택하거나 위치 정보를 입력할 수 있는 기능을 제공한다.</td>
    </tr>
    <tr>
      <td>민원 접수 기능</td>
      <td>사용자가 입력한 제목, 내용, 카테고리, 지도 위치 정보를 기반으로 민원을 등록하며, 등록된 민원은 기본적으로 ‘접수 완료’ 상태로 저장된다.</td>
    </tr>

    <tr>
      <td rowspan="5">민원 목록 조회 기능</td>
      <td>전체 민원 목록 조회 기능</td>
      <td>등록된 민원 전체 목록을 조회할 수 있는 기능을 제공한다. 사용자는 본인이 등록한 민원을 확인할 수 있고, 관리자는 전체 민원을 확인할 수 있다.</td>
    </tr>
    <tr>
      <td>민원 제목 표시 기능</td>
      <td>민원 목록에서 각 민원의 제목을 표시하여 사용자가 민원 내용을 쉽게 구분할 수 있도록 한다.</td>
    </tr>
    <tr>
      <td>카테고리 표시 기능</td>
      <td>민원 목록에서 각 민원의 카테고리를 표시하여 민원의 유형을 쉽게 파악할 수 있도록 한다.</td>
    </tr>
    <tr>
      <td>처리 상태 표시 기능</td>
      <td>민원 목록에서 현재 처리 상태를 표시한다. 처리 상태는 ‘접수 완료’, ‘검토 중’, ‘처리 중’, ‘처리 완료’ 단계로 구분한다.</td>
    </tr>
    <tr>
      <td>등록일 표시 기능</td>
      <td>민원 목록에서 민원이 등록된 날짜를 표시하여 사용자가 접수 시점을 확인할 수 있도록 한다.</td>
    </tr>

    <tr>
      <td rowspan="3">민원 상세 조회 기능</td>
      <td>민원 상세 내용 확인 기능</td>
      <td>사용자가 민원 목록에서 특정 민원을 클릭하면 해당 민원의 제목, 내용, 카테고리, 지도 위치, 처리 상태, 등록일을 상세하게 확인할 수 있다.</td>
    </tr>
    <tr>
      <td>지도 위치 확인 기능</td>
      <td>민원 상세 화면에서 민원이 발생한 위치 정보를 확인할 수 있도록 한다.</td>
    </tr>
    <tr>
      <td>처리 상태 확인 기능</td>
      <td>민원 상세 화면에서 해당 민원이 현재 어떤 처리 단계에 있는지 확인할 수 있도록 한다.</td>
    </tr>

    <tr>
      <td rowspan="4">관리자 민원 관리 기능</td>
      <td>관리자 민원 목록 확인 기능</td>
      <td>관리자가 시스템에 접수된 전체 민원 목록을 확인할 수 있는 기능을 제공한다.</td>
    </tr>
    <tr>
      <td>관리자 민원 상세 확인 기능</td>
      <td>관리자가 특정 민원을 선택하여 상세 내용을 확인하고, 민원 처리에 필요한 정보를 검토할 수 있도록 한다.</td>
    </tr>
    <tr>
      <td>처리 상태 변경 기능</td>
      <td>관리자가 민원의 처리 상태를 ‘접수 완료’, ‘검토 중’, ‘처리 중’, ‘처리 완료’ 단계로 변경할 수 있는 기능을 제공한다.</td>
    </tr>
    <tr>
      <td>민원 처리 현황 관리 기능</td>
      <td>관리자가 민원별 처리 상태를 관리함으로써 전체 민원의 진행 상황을 체계적으로 확인할 수 있도록 한다.</td>
    </tr>

    <tr>
      <td rowspan="4">예외 처리 기능</td>
      <td>미입력 항목 검증 기능</td>
      <td>민원 등록 시 제목, 내용, 카테고리, 위치 등 필수 항목이 입력되지 않은 경우 등록을 제한하고 안내 메시지를 출력한다.</td>
    </tr>
    <tr>
      <td>로그인 실패 처리 기능</td>
      <td>사용자가 잘못된 아이디 또는 비밀번호를 입력한 경우 로그인에 실패했다는 안내 메시지를 출력한다.</td>
    </tr>
    <tr>
      <td>권한 접근 제한 기능</td>
      <td>일반 사용자가 관리자 기능에 접근하거나, 로그인하지 않은 사용자가 민원 등록 기능에 접근할 경우 접근을 제한하고 안내 메시지를 출력한다.</td>
    </tr>
    <tr>
      <td>잘못된 요청 처리 기능</td>
      <td>존재하지 않는 민원 상세 페이지에 접근하거나 잘못된 요청이 발생한 경우 오류 메시지를 출력한다.</td>
    </tr>
  </tbody>
</table>
